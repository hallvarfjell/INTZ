# INTZ v11.1

1. Kjør `supabase_setup_v11_1.sql` i Supabase SQL Editor.
2. Last opp alle PWA-filene til GitHub Pages.
3. Lukk gamle faner og last appen på nytt. Cache: `intervall-cache-v111-sync-results-v1`.
4. Velg personlig profil, aktiver sky-synk og bruk samme synknøkkel på alle enheter.
5. Trykk Synk opp og Synk ned. Dette synkroniserer både økter og øktmaler.

Historisk økt:
- Grafen viser valgte serier for puls, watt, fart og RPE, med tid på x-aksen og verdiområder i grafen.
- Drag viser fart, watt, snittpuls siste 20 sekunder og puls-slope siste 60 sekunder.
- Pulssoner er LT-baserte: Z1 <85 % LT1, Z2 85 % LT1–LT1, Z3 LT1–LT2, Z4 LT2–105 % LT2, Z5 over 105 % LT2.
